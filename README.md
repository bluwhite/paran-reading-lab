# 파란 읽기연구실

웹캠 기반 한국어 문장 읽기 실험 도구입니다. 교사는 문장과 분석 구간을 설정하고 학생용 검사 링크를 만들 수 있습니다. 학생의 검사 결과는 교사용 링크에서 문장별·참가자별로 확인하고 CSV로 내보낼 수 있습니다.

- [운영 사이트](https://paran-reading-lab.epichawk20.chatgpt.site/)
- 카메라 영상은 브라우저에서 시선 좌표를 추정하는 데 사용합니다. 얼굴 영상, 화면, 음성을 녹화하거나 저장하지 않습니다.
- 서버에는 참가자 정보, 문장별 시간, 추정 시선 좌표와 분석 결과를 저장합니다. 참가자 이름은 검사 설정에서 선택적으로 수집합니다.

## 빌드와 별도 배포

```sh
node build.mjs
node --input-type=module --check < dist/server/index.js
```

빌드 결과물은 Cloudflare Worker용 ES 모듈인 `dist/server/index.js`입니다. 별도로 배포할 때는 D1 데이터베이스를 `DB`로 연결하고 `drizzle/0000_reading_lab.sql`을 적용합니다. 카메라 접근이 가능한 HTTPS 주소로 학생에게 검사 링크를 제공합니다.

교사용 접근 키는 32바이트 난수를 64자리 소문자 16진수로 표현한 값입니다. 키 원문은 교사가 보관하고, 원문 문자열의 SHA-256 해시를 Worker 환경 변수 `READING_LAB_ADMIN_SHA256`에 설정합니다. 교사는 첫 화면에서 키 원문을 입력해 검사를 생성합니다. 검사마다 학생용 링크와 교사용 보고서 링크가 각각 발급됩니다. 교사용 링크는 교사만 보관합니다.

이 저장소에는 운영 사이트의 접근 키, 데이터베이스 및 검사 결과가 포함되어 있지 않습니다.
